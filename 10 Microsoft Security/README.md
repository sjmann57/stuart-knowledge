# Microsoft Security Knowledge Base

An Obsidian-ready vault of **50 distilled Microsoft Security knowledge notes**, built from the 100-day LinkedIn writing programme (Stuart Mann, 2026).

## How to use
1. Open this folder as an **Obsidian vault** (or drop `notes/` into an existing vault).
2. Open **_MOC.md** — the Map of Content hub, grouped by product area, with `[[wikilinks]]` to every note.
3. The Obsidian graph view will show the cross-links between related topics.

## Note structure
Each note has YAML frontmatter (`title`, `product`, `day`, `published`, `source`, `impressions`, `tags`) and sections:
**Summary · Key facts · Licensing & prerequisites · Practitioner notes / gotchas · Microsoft Learn references · Related · Source**.

## Scope
Microsoft Security technical topics only — Entra, Defender family, Purview, Sentinel, Global Secure Access, Zero Trust, Security Exposure Management, Security Copilot and AI-agent security. Personal/career posts from the programme are not included.

## Caveats
- Product capabilities, previews and dates were current around **September 2026** — verify against Microsoft Learn before relying on specifics.
- Licensing lines are indicative; confirm current packaging.

_Source of record for each note is the linked LinkedIn article._
