# Microsoft Security Copilot

## Summary
Security Copilot is the generative-AI layer across the Microsoft security stack — compressing the analyst timeline through natural-language investigation, incident summarisation, KQL generation and guided response.

## Key facts
- Standalone experience plus embedded in Defender, Sentinel, Entra, Intune, Purview.
- Capabilities: incident summaries, guided response, script/file analysis, KQL generation, threat intel.
- Priced in Security Compute Units (SCUs) — provisioned + overage.
- Foundation for the Security Copilot agents (Day 84).

## Licensing & prerequisites
- SCU-based; also included for eligible Microsoft 365 E5/E7 customers (400 SCUs per 1,000 licences/month, capped 10,000).

## Practitioner notes / gotchas
- Compresses time-to-insight but keeps humans in command; value scales with the data and products connected.
- Watch SCU consumption — autonomous agents consume more than occasional prompts.
