# Where Microsoft security is heading — the agentic SOC

## Summary
Microsoft's direction: the agentic SOC — a deterministic, policy-bound autonomous-defence layer, a reasoning AI-agent layer above it, and humans providing intent, judgement and accountability. AI is now both something to secure and something that secures.

## Key facts
- Three layers: autonomous defence (deterministic, policy-bound, high-confidence auto-action) → agents (reason, coordinate, orchestrate) → humans (intent, judgement, accountability).
- Already live: automatic attack disruption (~3-min average ransomware containment; tens of thousands contained monthly at 99.99% confidence).
- Two-sided AI: securing AI (Agent 365, Agent ID, Purview for AI, Defender for AI) and using AI to secure (Copilot agents, autonomous defence).
- Adoption maturity: SOC I (unify platform) → SOC II (accelerate with genAI/task agents) → SOC III (agentic automation).

## Licensing & prerequisites
- Capability-dependent; autonomous action needs the underlying products deployed and configured (foundations).

## Practitioner notes / gotchas
- Machine speed for containment, human judgement for consequence — don't jump straight to full autonomy.
- The people question: if agents take the entry-level triage work, plan how juniors still learn the craft.
