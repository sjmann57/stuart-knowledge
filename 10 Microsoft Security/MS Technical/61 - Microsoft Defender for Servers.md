# Microsoft Defender for Servers

## Summary
Defender for Servers extends threat protection to VMs and machines across Azure, AWS, GCP and on-prem, with two plans and a set of controls many organisations never switch on.

## Key facts
- Plan 1: core EDR via Defender for Endpoint integration.
- Plan 2: adds vulnerability assessment, agentless scanning, file integrity monitoring, just-in-time VM access, adaptive application controls, free data ingestion allowance.
- Integrates Defender for Endpoint onto server workloads.
- Just-in-time VM access reduces exposed management ports.

## Licensing & prerequisites
- Per-server-hour pricing; Plan 1 vs Plan 2 feature split.

## Practitioner notes / gotchas
- The 'controls most haven't turned on': JIT access, FIM, adaptive application controls.
- Choose the plan by the capabilities you'll actually operate, not the highest tier by default.
