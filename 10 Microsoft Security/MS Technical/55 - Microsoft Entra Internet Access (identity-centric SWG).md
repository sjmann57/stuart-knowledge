# Microsoft Entra Internet Access (identity-centric SWG)

## Summary
Entra Internet Access is an identity-centric secure web gateway — protecting access to internet and SaaS apps with Conditional Access, tenant restrictions and web content controls tied to identity.

## Key facts
- Secures outbound internet/SaaS traffic with identity-aware policy.
- Universal Conditional Access and universal tenant restrictions extend controls to the network layer.
- Web content filtering and threat protection for browsing.
- Integrates with Defender for Cloud Apps for SaaS control.

## Licensing & prerequisites
- Global Secure Access / Entra Internet Access licensing; GSA client deployment.

## Practitioner notes / gotchas
- Brings Conditional Access to general web/SaaS traffic, not just Entra-integrated apps.
- Strongest combined with Private Access + Defender for Cloud Apps (Day 56).
