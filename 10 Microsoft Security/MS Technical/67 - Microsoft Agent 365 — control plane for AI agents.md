# Microsoft Agent 365 — control plane for AI agents

## Summary
Agent 365 is the control plane to observe, govern and secure AI agents at scale — a single catalogue and management surface as agents proliferate across an organisation. (Top technical performer: 2,684.)

## Key facts
- Unified registry/catalogue and visibility of AI agents across the tenant.
- Observe / Govern / Secure model: see all agents, apply policy, protect them.
- Builds on Entra Agent ID for identity and integrates with Purview and Defender for the AI estate.
- Agent registry is converging into Agent 365 (Entra Agent registry blades retired May 2026).

## Licensing & prerequisites
- Evolving product — verify current packaging/licensing; parts announced/preview.

## Practitioner notes / gotchas
- Agents without registration are shadow agents — the point of a control plane is to end that.
- Identity, data and threat protection for agents all hang off this foundation.
