# Microsoft Defender for Cloud — Secure Score, CSPM & the cloud gap

## Summary
Introduction to Defender for Cloud: cloud security posture (Secure Score, CSPM) plus workload protection across multicloud. The 'cloud security gap' is the space between an Azure Secure Score number and controls actually being enforced.

## Key facts
- Secure Score quantifies posture against the Microsoft Cloud Security Benchmark.
- Free foundational CSPM vs paid Defender CSPM (attack path analysis, agentless scanning, data-aware posture).
- Covers Azure, AWS and GCP.
- Feeds Defender XDR and Security Exposure Management.

## Licensing & prerequisites
- Foundational CSPM is free; Defender CSPM and workload plans are paid per resource/hour.

## Practitioner notes / gotchas
- A Secure Score is a starting point, not proof of protection — recommendations still need remediating.
- See Day 60 for the CSPM vs CWPP architecture split.
