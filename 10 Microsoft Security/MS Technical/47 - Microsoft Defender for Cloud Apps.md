# Microsoft Defender for Cloud Apps

## Summary
Defender for Cloud Apps is Microsoft's CASB: discovery and control for SaaS/cloud app usage, shadow-IT visibility, session controls and app governance — a layer most organisations own but haven't switched on.

## Key facts
- Cloud Discovery surfaces shadow IT from network/endpoint signals (34,000+ app catalogue).
- App connectors and Conditional Access App Control enable real-time session controls (block download, monitor).
- App governance monitors OAuth apps and their permissions (OAuth attack paths).
- Note: file policies/DLP are moving to Microsoft Purview (DfCA file policies retire 6 Jan 2027).

## Licensing & prerequisites
- Included in Microsoft 365 E5 / E5 Security; some capabilities licensed separately.

## Practitioner notes / gotchas
- Real-time session control via Conditional Access App Control is the standout capability people miss.
- Plan the DLP/file-policy migration to Purview now (see Day 83).
