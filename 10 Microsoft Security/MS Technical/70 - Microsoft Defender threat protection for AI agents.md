# Microsoft Defender threat protection for AI agents

## Summary
Defender extends detection, real-time blocking, posture management and investigation to AI agents — treating the AI estate as something that needs threat protection, not just governance.

## Key facts
- Detection of threats and anomalous behaviour involving AI agents.
- Real-time blocking / protective action against compromised agents.
- Posture management for the AI estate; agent identities and relationships surface in security/exposure experiences.
- Feeds Defender XDR incidents and the unified security picture.

## Licensing & prerequisites
- Evolving/preview; verify current status and prerequisites.

## Practitioner notes / gotchas
- Completes the securing-AI trio with Agent ID (identity) and Purview (data).
- Agents can be both targets and, increasingly, defenders (Security Copilot agents).
