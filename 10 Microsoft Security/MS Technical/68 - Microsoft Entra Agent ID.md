# Microsoft Entra Agent ID

## Summary
Entra Agent ID gives AI agents a first-class identity your policies can actually enforce — purpose-built identity constructs so agents can be authenticated, authorised, governed and protected like any other actor.

## Key facts
- Dedicated identity constructs for AI agents within Microsoft Entra.
- Conditional Access can target agent identities and agent identity blueprints.
- Identity Protection can assess agent risk; identity governance (ownership, sponsorship, lifecycle) extends to agents.
- Microsoft recommends agent-specific Conditional Access — agents can't satisfy interactive MFA like a person.

## Licensing & prerequisites
- Evolving/preview capability; verify current status and licensing.

## Practitioner notes / gotchas
- Agents are a new class of identity — the same disciplines (least privilege, governance, monitoring) apply.
- Don't let agents inherit human user policies; design agent-specific controls.
