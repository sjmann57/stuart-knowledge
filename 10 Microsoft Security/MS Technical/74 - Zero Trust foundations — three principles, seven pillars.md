# Zero Trust foundations — three principles, seven pillars

## Summary
Zero Trust is a security strategy, not a product: never trust, always verify, applied through three principles across seven (plus AI) technology pillars.

## Key facts
- Principles: verify explicitly; use least privilege access; assume breach.
- Pillars: identity, endpoints/devices, data, apps, infrastructure, network, security operations (SecOps).
- AI is a major new scenario where the same principles apply — not simply an eighth pillar.
- The strategy sits above every product and decides what 'good' looks like.

## Licensing & prerequisites
- Strategy, not a licence — every control below should trace to a principle.

## Practitioner notes / gotchas
- Verification is continuous, evaluated as conditions/risk change, not a one-time gate.
- Most orgs practise one or two principles well; the value is doing all three.
