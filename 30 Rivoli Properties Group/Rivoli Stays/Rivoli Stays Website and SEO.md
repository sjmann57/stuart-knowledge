# Rivoli Stays — Website and SEO

Site: **rivolistays.co.uk**

## SEO and AI-visibility audit findings

An SEO and AI visibility audit of rivolistays.co.uk identified the following critical issues:

- **Duplicate homepage content** — caused by the Divi page builder
- **Broken internal property links**
- **Missing schema markup**
- **Testimonial reviews embedded as images** — not indexable by search engines
- **Booking subdomain diluting domain authority** — a separate booking subdomain splits authority away from the main domain
- **Viewport meta tag fix** — scoped but not confirmed fixed

## Platform

Built on the **Divi theme/builder**, self-hosted WordPress — the same platform used for rivolipropertymanagement.co.uk (see [[Rivoli Property Management — Sister Brand]]).

## Status

These are audit *findings* — no confirmation yet that fixes have been implemented. Treat this as an open action list rather than a changelog.
