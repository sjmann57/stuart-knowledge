# Rivoli Stays — Operations and Tooling

The tech stack Rivoli Stays runs on, as confirmed by Stuart. Descriptions below are general-knowledge notes on what each tool typically does in an SA/STR business — none of the operational detail (how each is configured, which properties are on which channel, etc.) is confirmed yet, so treat the "typical use" lines as context, not as documented fact about Rivoli Stays' actual setup.

| Tool | Category | Typical use |
|---|---|---|
| **Guesty Lite** | Property management system (PMS) | Channel-manager-linked booking/reservation management across OTAs |
| **PriceLabs** | Dynamic pricing | Automated rate adjustment based on demand, seasonality, comp set |
| **Airbnb** | OTA / booking channel | Direct booking channel |
| **Booking.com** | OTA / booking channel | Direct booking channel |
| **Vrbo** | OTA / booking channel | Direct booking channel |
| **CheKin** | Guest verification / check-in | Digital check-in, ID verification, guest registration |
| **SuiteOp** | Operations / guest experience platform | Task management, guest communication, property ops |
| **Pipedrive** | CRM | Sales/lead pipeline management |
| **PropertyMarketIntel** | Market data | Property market intelligence/comparables |
