# Option 2 — STR Conversion & Management

- The landlord **keeps ownership**.
- Rivoli runs the property as a **short-term stay**, using the same systems and processes Rivoli Stays already operates on (Guesty Lite, PriceLabs, CheKin, SuiteOp — see [[RM - Shared Systems with Rivoli Stays]]).
- Rivoli takes a **management commission** instead of a fixed lease.
- **Income is variable**, tied to performance — this is the core distinction from Option 1. Never blur the two in copy or advice.
- Targeting uses Rivoli Stays' existing guest-demand avatar as a baseline for judging property/location fit (see [[RM - Guest Demand Avatar]]), widened to leisure/tourism where the location supports it.
