# Website — rivolipropertymanagement.co.uk

- **Hosting:** self-hosted WordPress on GoDaddy hosting (not WordPress.com) — a WordPress.com connector can't reach it directly.
- **Builder:** Divi theme/builder — same as rivolistays.co.uk.
- **Current state (checked 10 Sept 2026):** single page — Home / Benefits / About Us / How It Works / Contact — pitching only [[RM - Option 1 (Rent-to-Rent)|Option 1]]'s guaranteed-rent message.
- **Needed rework:** introduce [[RM - Option 2 (STR Conversion & Management)|Option 2]] alongside Option 1 within the **same funnel**, not as a separate site or a second silo. One shared enquiry funnel presenting both options, though individual ad campaigns may steer toward a preferred option.

## Implementation path
Pushing a change into Divi needs either:
- A WordPress Application Password (scoped, revocable) for the REST API, or
- A standalone mockup/prototype built outside WordPress for review and manual implementation.

Check which path is wanted before starting a page draft — they produce different kinds of output.
