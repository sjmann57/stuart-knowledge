# Shared Systems with Rivoli Stays

[[RM - Option 2 (STR Conversion & Management)|Option 2]] runs landlord properties on the same operating stack Rivoli Stays already uses for its own portfolio:

- **Guesty Lite** — channel/booking management
- **PriceLabs** — dynamic pricing
- **CheKin** — guest check-in
- **SuiteOp** — operations/guest experience

Rivoli Stays' wider toolset also includes Airbnb, Booking.com, Vrbo, Pipedrive, and PropertyMarketIntel — worth noting which of these RM's Option 2 actually touches once a landlord property is onboarded (open question — see [[RM - Open Questions]]).
