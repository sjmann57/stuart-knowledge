# Biography

## Overview

Stuart Mann is a Microsoft Security Architect, property investor, business owner, Scout volunteer and endurance athlete based in Derbyshire, UK.

He works across Microsoft security architecture, identity, cloud security, data security and AI governance, while also building a property business focused on serviced accommodation, property development and property management.

## Professional Background

Stuart has more than eight years of experience in cyber security, with a strong focus on Microsoft security technologies.

His core areas include:

- Microsoft Entra ID
- Conditional Access
- Privileged Identity Management
- Identity Protection
- Microsoft Defender XDR
- Microsoft Sentinel
- Microsoft Purview
- Defender for Cloud
- Zero Trust
- Microsoft Security Copilot
- Microsoft Agent 365
- AI security and governance
- Power Platform governance

He has experience designing security architectures, creating SOC services, implementing detection engineering, supporting Zero Trust programmes and working in regulated environments including healthcare and financial services.

His Microsoft security certifications include:

- SC-100
- SC-200
- SC-300
- SC-400
- AZ-500
- MS-101
- ISC2 CCSP

He has also contributed to work recognised through Microsoft's Partner of the Year programme.
